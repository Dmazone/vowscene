# VowScene

웨딩 영상작가에게 60~90초 분량의 맞춤형 러브스토리 내레이션 대본을 판매하기 위한 7일 검증 프로젝트다.

## 현재 상태

- 공개 주소: `https://dmazone.github.io/vowscene/`
- 영문 판매 페이지: `index.html`
- 고객용 주문 정보 작성 페이지: `intake.html`
- 운영자용 DM 명단판: `leads.html`
- 초기 가격: US$29
- 납품 시간: 주문 정보 수령 후 12시간
- 포함 사항: 전체 대본, 장면 배치표, 수정 1회
- 결제: PayPal 계좌 인증 완료 후 인보이스 방식
- 서버·데이터베이스·유료 API: 없음

## 판매 전 CEO가 할 일

1. PayPal 계좌 인증을 완료한다.
2. `index.html` 하단의 `CONTACT_EMAIL`에 주문용 이메일을 입력한다.
3. 본인 Instagram 계정의 프로필과 최근 게시물을 정리한다.
4. 첫 DM은 하루 10~15건씩 직접 보낸다. 자동 대량 발송은 사용하지 않는다.

## 실행 방법

`index.html`을 브라우저에서 직접 열 수 있다. 공개 전에는 로컬 서버로 확인한다.

```powershell
python -m http.server 8080
```

브라우저에서 `http://localhost:8080/VowScene/`을 연다.

## 첫 검증 기준

- 검증된 대상 30명에게 개인화 DM 발송
- 샘플 수신 동의 5명 이상
- 구체적인 가격 문의 2명 이상
- US$29 결제 1건

10명에게 보낸 뒤 샘플 요청이 한 건도 없으면 문구를 수정한다. 30명 발송 후 결제가 없으면 기능을 추가하지 않고 타깃·상품·가격 중 하나를 바꾼다.

## 폴더

- `index.html`: 고객용 판매 페이지
- `intake.html`: 결제 후 고객에게 보내는 이야기 수집 페이지
- `leads.html`: 후보·DM·답장·결제를 관리하고 CSV로 백업하는 로컬 명단판
- `OPERATIONS.md`: DM부터 결제·납품까지의 운영 절차
- `samples/`: 세 가지 영문 샘플 원고
- `scripts/build_sample_pdfs.py`: 샘플 PDF 생성기
- `output/pdf/`: 고객에게 보여줄 PDF

## 개인정보 원칙

- 커플의 전체 이야기는 공개 샘플에 사용하지 않는다.
- 주문 정보는 공개 저장소에 커밋하지 않는다.
- 고객 영상은 허락 없이 다운로드하거나 재편집하지 않는다.
- 작업 완료 후 보관 기간을 고객에게 알리고, 삭제 요청을 받으면 제거한다.
